# Ableton Project Manager

A desktop app for browsing, organizing, and auditioning a large Ableton Live project library — built for anyone with years of scattered `.als` files spread across drives and folders who wants one searchable place to find, tag, and play them.

**[Download for Windows](https://github.com/Zortheus/Ableton-Project-Manager-Releases/releases/latest)**

![Ableton Project Manager screenshot](screenshot.png)

## Features

- **Instant search across your entire library** — every project, every drive, one list
- **Status, favorites, and collections** — tag what's active, done, or worth revisiting
- **Colored waveform previews** — audition bounces without opening Ableton, frequency-colored like a DJ waveform (red = bass, green = mids, blue = highs)
- **Backup history** — see every auto-saved version of a project and how many exist at a glance
- **Auto-updating** — stays current on its own

## Install

Download the installer above and run it — installs like any other Windows app, with a desktop shortcut. Unsigned, so Windows may show an "Unknown publisher" warning on first run; click through it to continue.
